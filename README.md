# Grok Consumer App

Interactive prototype of **YourAI** — a consumer-first intent marketplace.

Private chat stays in a vault. The user previews a sanitized card, opens it to local contractors, picks up to three, and only then unlocks name and phone.

## Click path

1. Preview a card
2. Hide budget (optional)
3. Open to 3 local contractors
4. View PeakView → choose → Thursday 6:00
5. Activity log
6. Close card
